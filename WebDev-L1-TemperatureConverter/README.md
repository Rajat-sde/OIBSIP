# Task 3: Temperature Converter Web App

An interactive temperature converter tool built with vanilla JavaScript that performs real-time unit conversions and input validation as part of the Oasis Infobyte Web Development and Designing Internship (OIBSIP).

## 📌 Features
- **Multi-Unit Input:** Allows users to input values in Celsius, Fahrenheit, or Kelvin via a dropdown selector.
- **Simultaneous Output Display:** Calculates and displays conversions for all three temperature units at once.
- **Input Validation:** Rejects empty or non-numeric inputs with clear, user-friendly error messages.
- **Absolute Zero Edge Case Handling:** Validates against physical temperature limits and alerts users if input falls below absolute zero ($-273.15^\circ\text{C}$ / $0\text{K}$).
- **Centered UI Layout:** Clean, accessible card interface with responsive controls.

## 🛠️ Tech Stack
- **HTML5:** Form controls and structured layout markup.
- **CSS3:** Custom variables, grid layout, and card styling.
- **JavaScript (ES6+):** Event handling, arithmetic parsing, edge-case validation, and DOM rendering.

## 🚀 How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any web browser to use the app.
