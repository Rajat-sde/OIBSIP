# Task 1: Responsive Landing Page

A minimal, high-performance static landing page built with semantic HTML5 and CSS3 as part of the Oasis Infobyte Web Development and Designing Internship (OIBSIP).

## 📌 Features
- **Sticky Navigation Bar:** Contains brand logo and navigation links for smooth page traversal.
- **Hero Section:** Features a prominent headline, subheadline, and primary Call-to-Action (CTA) button.
- **Content Sections:** Includes structured Features and CTA sections using modern layout modules.
- **Footer:** Displays copyright details and placeholder social media links.
- **Responsive Layout:** Adapts fluidly across desktop, tablet, and mobile viewports using CSS Flexbox and Grid.

## 🛠️ Tech Stack
- **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<section>`, `<footer>`).
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, and Media Queries.

## 🚀 How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any web browser or launch it using VS Code **Live Server**.
